# 医疗报告解读

1. 确认报告类型、时间、完整性和单位；缺页或图像不可读时明确说明。
2. 使用附件工具提取受控文本和 metadata，不展示服务器绝对路径。
3. 按“原文所见 / 报告结论 / 通俗解释 / 需补充信息”组织。
4. 数值必须保留单位和参考区间；不同实验室参考值不可混用。
5. 不从单一报告推导确定诊断，不补写未出现的病史或检查。
6. 对可能紧急的异常提示及时就医，对其他内容建议结合症状由医生复核。
7. DICOM 或切片预览只能标为非诊断级辅助显示。
